#  Student Enquiry CRM Dashboard

##  About the Project

The Student Enquiry CRM Dashboard is a responsive web application designed to help educational institutions manage student enquiries efficiently. It displays student information, tracks enquiry statuses, and provides follow-up suggestions to support admission counsellors.

The application fetches user information from the JSONPlaceholder API and transforms it into sample student enquiry records.

##  Features

*  Display student enquiry records
*  Search for students by name
*  View detailed student information
*  Track total, new, interested, and closed enquiries
*  Display enquiry status, interested course, and notes
*  Generate follow-up summaries based on enquiry status
*  Fetch data from a public API
*  Display loading and error states with a retry option
*  Responsive dashboard interface

##  Technologies Used

* JSONPlaceholder Users API
