#  AI Data Analyst Assistant

##  About the Project

AI Data Analyst Assistant is an AI-powered web application that helps users analyse business data using natural language. Users can upload CSV files, ask questions about their data in simple English, and receive meaningful insights without writing complex formulas or code.

The project aims to make data analysis easier and more accessible for students, business owners, and non-technical users.

##  Features

* **CSV File Upload:** Upload your own CSV dataset or use the built-in sample sales data.
* **Data Preview:** View dataset columns, rows, and a preview of the uploaded data.
* **Natural Language Questions:** Ask questions about revenue, sales, trends, and category comparisons.
* **Interactive Charts:** Visualise data using bar charts and line charts.
* **AI-Powered Insights:** Get easy-to-understand answers using Claude AI.
* **Human Review Alerts:** Flag questions that cannot be reliably answered using the available data.

##  Technologies Used

* **HTML** – Structures the application.
* **CSS** – Styles the user interface.
* **JavaScript** – Handles application logic and user interactions.
* **Claude AI (Anthropic API)** – Generates natural-language answers based on the provided dataset.
* **PapaParse** – Parses CSV files in the browser.
* **Chart.js** – Creates interactive data visualisations.

##  How It Works

1. Upload a CSV file or select the sample dataset.
2. Preview the available data and columns.
3. Enter a question in simple English.
4. The application sends the question and dataset to Claude AI.
5. The assistant generates an answer based on the supplied data.
6. Relevant charts are displayed to make insights easier to understand.
7. Questions requiring additional information or analysis are flagged for human review.
