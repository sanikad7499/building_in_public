#  AI-Assisted Daily Task Manager

##  About the Project

AI-Assisted Daily Task Manager is a simple, responsive web application designed to help users organise and manage their daily tasks efficiently. It provides an interactive interface to create, update, track, and complete tasks in one place.

##  Features

*  Add new tasks
*  Edit and delete tasks
*  Mark tasks as completed
*  Search and filter tasks
*  Set task priorities and categories
*  Add due dates
*  Track task progress with a progress bar and counters
*  Dark mode
*  Automatically save tasks using browser Local Storage
*  Responsive user interface
*  Confirmation dialog before deleting tasks

##  Technologies Used

* HTML
* CSS
* JavaScript
* Browser Local Storage
